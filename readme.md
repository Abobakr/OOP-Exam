# مشروع إدارة الامتحانات

هذا المشروع عبارة عن مثال بلغة Java لكلاس `Exam` مع كلاس مشتقة `LabExam` وكلاس مشتقة إضافية `FinalExam`. الهدف هو تمثيل امتحانات الطلاب، تحويل الدرجات من النسبة المئوية إلى نظام المعدل التراكمي، وحساب الدرجات الكلية للامتحانات العملية والنهائية.

## الملفات الموجودة

- `App.java`
  - يحتوي على دالة `main` لتشغيل البرنامج.
  - ينشئ كائنات من الأصناف `Exam` و `LabExam` و `FinalExam`.
  - يحسب الدرجات ويطبع النتائج، ويختبر صلاحية بيانات الامتحان.

- `Exam.java`
  - يمثل امتحانًا عامًا.
  - يحتوي الحقول:
    - `id`، `student_id`، `subject_id`، `date`، `degree`، `in_gpa`
  - يحتفظ بمعامل تحويل `CONV_RATE` لتحويل الدرجة من نسبة مئوية إلى نظام GPA.
  - يوفر الأساليب:
    - `getDegree()` و `setDegree(double degree)`
    - `convertToGPA()` لتحويل الدرجة إذا لم تكن بالفعل في نظام GPA.
    - `isValid()` لفحص صحة الامتحان عبر محاكاة استدعاءين `getIdFromServer` و `getIdFromLocalDB`.

- `LabExam.java`
  - يمتد من `Exam` ليضيف خصائص الامتحان العملي.
  - يحتوي الحقول:
    - `lab_name` و `lab_degree`
  - يعيد تعريف `getDegree()` لحساب مجموع درجة الاختبار النظري والعملي.

- `FinalExam.java`
  - يمتد من `LabExam` ليضيف معلومات الامتحان النهائي.
  - يحتوي الحقول:
    - `examination_hall` و `final_degree`
  - يعيد تعريف `getDegree()` لحساب مجموع درجات الامتحان النظري والعملي والنهائي.


## السلوك المتوقع

- يقوم `App` بإنشاء امتحانين عامين (`exam_1` و `exam_2`) ثم يحول درجاتهما إلى نظام GPA إذا كانت الدرجات في النسبة المئوية.
- ينشئ امتحانًا عمليًا (`LabExam`) ويطبع مجموع درجاته.
- ينشئ امتحانًا نهائيًا (`FinalExam`) ويطبع مجموع درجاته بالكامل.
- يتحقق من صحة بيانات كل امتحان عام عبر `isValid()`.

## ملاحظات

- إذا كانت الدرجة خارج النطاق من 0 إلى 100، فسيطبع `setDegree` رسالة خطأ ولن يغيّر القيمة.
- الدالتان `getIdFromServer` و `getIdFromLocalDB` تعملان بمحاكاة لتعطي قيمة ثابتة.
- يمكنك تعديل البيانات في `App.java` لإضافة حالات امتحان جديدة أو اختبار سلوك الدوال المختلفة.

## الهدف التعليمي

- فهم مفهوم البرمجة الكائنية (OOP) في Java.
- التعرف على الوراثة (`extends`) وإعادة تعريف الأساليب (`@Override`).
- تطبيق دوال تحويل ومعايير صلاحية البيانات.
- بناء برنامج بسيط لإدارة معلومات امتحان.
